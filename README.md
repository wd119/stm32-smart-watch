# STM32 可编程手表

基于 **STM32F103C8T6** 的单机、离线、三按键手持式多功能数字手表。系统以一块 0.96 寸 128×64 单色 OLED 作为全部输出，三个物理按键作为全部输入，集成时钟、时间设置、秒表、手电筒、姿态显示、水平仪、小恐龙游戏、表情动画、电量显示与长按关机等功能。

> 仓库地址：<https://github.com/wd119/stm32-smart-watch>

---

## 功能特性

| 功能 | 说明 |
| :--- | :--- |
| 时钟显示 | 显示年-月-日与时:分:秒，秒级刷新；RTC 由 VBAT 后备供电，断电不丢时 |
| 时间设置 | 逐项调整年、月、日、时、分、秒，修改即时写入 RTC |
| 主菜单 | 横向滚动列表，带平滑位移动画 |
| 秒表 | 计时精度 1 秒，支持开始 / 停止 / 清零 |
| 手电筒 | 白光 LED 照明，可开关 |
| 姿态显示 | 实时显示 Roll / Pitch / Yaw 三轴角度（MPU6050） |
| 水平仪 | 以圆形气泡直观指示水平状态 |
| 小恐龙游戏 | 跳跃躲避障碍物的横版跑酷游戏，含计分 |
| 表情动画 | 眨眼表情动画 |
| 电池电量 | 时钟页显示电量百分比与图形化电池图标（数值待校准） |
| 长按关机 | 长按 K3 约 1 秒触发系统断电 |

## 硬件平台

| 项目 | 规格 |
| :--- | :--- |
| 主控 | STM32F103C8T6，ARM Cortex-M3，最高 72 MHz |
| Flash / SRAM | 64 KB / 20 KB |
| 显示 | 0.96 寸 OLED，128×64 单色，SSD1306，I2C 接口 |
| 姿态传感器 | MPU6050，三轴加速度计 + 三轴陀螺仪，I2C 接口 |
| 实时时钟 | 内置 RTC，LSE 32.768 kHz 晶振，VBAT 后备供电 |
| 输入 | 三按键（K1 / K2 / K3），K3 支持长按识别 |
| 输出 | OLED、白光 LED 手电筒 |
| 电源 | 锂电池供电，分压后接 ADC 采样 |
| 调试 | ST-Link（SWD） |

## 引脚分配

| 引脚 | 模式 | 用途 |
| :--- | :--- | :--- |
| PA0 | 模拟输入 | 电池电压采样（ADC1_IN0） |
| PA4 | 上拉输入 | 按键 K3（短按确定 / 长按关机） |
| PA6 | 上拉输入 | 按键 K2 |
| PB1 | 上拉输入 | 按键 K1 |
| **PB8** | 开漏输出 | **OLED 软件 I2C SCL** |
| **PB9** | 开漏输出 | **OLED 软件 I2C SDA** |
| **PB10** | 开漏输出 | **MPU6050 软件 I2C SCL** |
| **PB11** | 开漏输出 | **MPU6050 软件 I2C SDA** |
| PB12 | 推挽输出 | 电源 / 电池采样支路控制（需对照原理图核实） |
| PB13 | 推挽输出 | 电源自锁控制，拉低执行关机（需对照原理图核实） |
| PB15 | 推挽输出 | 白光 LED 手电筒，低电平点亮 |

> **注意**：本工程的 OLED 与 MPU6050 使用**两套独立的软件 I2C**，分别位于 PB8/PB9 与 PB10/PB11，并非共用同一条总线。软件 I2C 为开漏输出，两条总线均需外部上拉电阻（建议 4.7 kΩ 接 3.3 V）。

## 按键与操作

| 按键 | 短按 | 长按（约 1 s） |
| :--- | :--- | :--- |
| K1（PB1） | 上移 / 减 | — |
| K2（PA6） | 下移 / 加 | — |
| K3（PA4） | 确定 / 进入 | 关机 |

首页提供「菜单」与「设置」两个入口；菜单内可进入各功能页面，各页面均以 K3 返回。

## 软件架构

工程按三层组织，依赖方向严格自上而下：

```
User/    入口与中断向量      main.c、stm32f10x_it.c
  ↓
App/     业务逻辑与页面      时钟、菜单、秒表、姿态、游戏、设置、页面框架
  ↓
Bsp/     板级驱动            OLED、MPU6050、RTC、ADC、按键、LED、定时器
```

- **Bsp 层**：OLED 显示与字库、软件 I2C、MPU6050、RTC、ADC 电量采样、按键扫描、LED、定时器。
- **App 层**：各功能页面与菜单调度；`app_page.c` 提供统一的页面框架（上下选择、确定、长按关机）。
- **User 层**：系统入口 `main.c` 与中断服务 `stm32f10x_it.c`。

系统时基由 TIM2 提供，1 ms 中断内依次完成按键扫描、秒表计时与游戏逻辑推进。

## 构建与烧录

1. 安装 **Keil MDK（µVision）** 与 **ARMCC** 编译器。
2. 通过 Pack Installer 安装 **STM32F1** 器件支持包。
3. 打开工程 `Project.uvprojx`，器件已配置为 **STM32F103C8**（Flash 64 KB / SRAM 20 KB）。
4. 编译（`F7`），输出位于 `Objects/Project.axf`。
5. 使用 **ST-Link** 通过 SWD 下载并复位运行。

工程包含路径：

```
.\Start;.\Library;.\User;.\Bsp;.\App
```

预定义宏：`USE_STDPERIPH_DRIVER`。

## 源码说明

- 源码文件采用 **GBK** 编码，编辑时请保持原编码，避免中文注释乱码。
- OLED 的 SCL/SDA 固定在 **PB8/PB9**（`Bsp/OLED.c`），MPU6050 的 SCL/SDA 在 **PB10/PB11**（`Bsp/MyI2C.c`），两者不可混淆。
- RTC 初始时间硬编码为 `2026-09-07 18:15:00`（`Bsp/MyRTC.c`），仅首次上电（`BKP_DR1 != 0xA5A5`）时写入，此后由 VBAT 维持。
- `Bsp/Buzzer.c` 为预留驱动，当前工程未调用。
- `PB12` 同时出现在 `Bsp/LED.c` 与 `Bsp/Buzzer.c` 中，使用前需确认原理图。
